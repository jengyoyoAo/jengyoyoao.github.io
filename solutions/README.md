# Online Judge solutions

Store the source code and explanatory notes for each solved problem here, grouped by platform. The website’s platform pages link to these folders.

## Adding a solution

For each problem, add a Markdown note and the matching source file in that platform’s folder. Use the problem ID or a short title as the shared filename, for example `0001-two-sum.md` and `0001-two-sum.py`. Use the source extension for the language you actually used.

Start from [TEMPLATE.md](TEMPLATE.md) for the write-up. Link to the statement, explain the key idea, include complexity where it applies, and add a short takeaway.

## Platforms

- [CSES](cses/)
- [ZeroJudge](zerojudge/)
