<section class="vocabulary-entry" aria-labelledby="backup">
<h2 id="backup">backup <span class="vocabulary-pos">[n.; attributive]</span></h2>

**Meaning:** <span lang="zh-Hant">備份；備用方案或設備；支援人力</span>

### Collocations & patterns

- a backup plan / file / copy / system
- a backup battery
- a data backup; backup data
- call for backup
- back up your files
- The traffic is backing up.

### Example

Keep a backup copy of the report before editing it.

<span class="reading-translation" lang="zh-Hant">編輯報告前，請保留一份備份。</span>

### Usage note

<p lang="zh-Hant"><strong>Backup</strong> 一字是名詞或名詞前的修飾語；動詞片語要寫成兩字 <strong>back up</strong>，如 back up files（備份檔案）、back up a vehicle（倒車）。<strong>Traffic backs up</strong> 是車流回堵；<strong>call for backup</strong> 是請求支援。 <a href="https://dictionary.cambridge.org/dictionary/english/backup">Dictionary: backup</a> · <a href="https://dictionary.cambridge.org/dictionary/english/back-up">back up</a></p>

</section>

<section class="vocabulary-entry" aria-labelledby="boardroom">
<h2 id="boardroom">boardroom <span class="vocabulary-pos">[n.]</span></h2>

**Meaning:** <span lang="zh-Hant">董事會會議室；亦可指高階決策的場合</span>

### Collocations & patterns

- in the boardroom
- a boardroom meeting / table / discussion
- a boardroom decision / battle
- boardroom politics

### Example

The directors gathered in the boardroom to discuss the merger.

<span class="reading-translation" lang="zh-Hant">董事們在董事會會議室集合，討論合併案。</span>

### Usage note

<p lang="zh-Hant"><strong>Boardroom</strong> 是場所，也可延伸修飾高階管理層的決策或角力，例如 boardroom politics（高層權力角力）。不是所有一般會議室都稱為 boardroom。</p>

</section>

<section class="vocabulary-entry" aria-labelledby="booklet">
<h2 id="booklet">booklet <span class="vocabulary-pos">[n.]</span></h2>

**Meaning:** <span lang="zh-Hant">小冊子；薄手冊</span>

### Collocations & patterns

- an instruction / information / travel booklet
- a free booklet
- a booklet of coupons
- a booklet about safety rules
- a booklet for new employees

### Example

Each new employee receives a booklet about workplace safety.

<span class="reading-translation" lang="zh-Hant">每位新進員工都會收到一本職場安全手冊。</span>

### Usage note

<p lang="zh-Hant"><strong>A booklet for new employees</strong> 是給新進員工的小冊子。<strong>A booklet of coupons</strong> 指一本優惠券冊；<strong>about</strong> 帶出手冊主題，<strong>for</strong> 帶出使用對象。</p>

</section>

<section class="vocabulary-entry" aria-labelledby="brainstorm">
<h2 id="brainstorm">brainstorm <span class="vocabulary-pos">[vi.; vt.; n.]</span></h2>

**Meaning:** <span lang="zh-Hant">腦力激盪；集思廣益；突然想到的點子</span>

### Collocations & patterns

- brainstorm ideas / solutions
- brainstorm with classmates
- hold a brainstorming session
- have a brainstorm
- a brilliant brainstorm

### Example

The team held a brainstorming session to generate new ideas.

<span class="reading-translation" lang="zh-Hant">團隊舉辦了一場腦力激盪會議，以提出新點子。</span>

### Usage note

<p lang="zh-Hant"><strong>Brainstorm</strong> 可作動詞；<strong>a brainstorming session</strong> 是一場集思廣益的會議。<strong>Have a brainstorm</strong> 可表示突然想到點子，但表達「腦力激盪會議」時，用 brainstorming session 更清楚。</p>

</section>

<section class="vocabulary-entry" aria-labelledby="broker">
<h2 id="broker">broker <span class="vocabulary-pos">[n.; vt.]</span></h2>

**Meaning:** <span lang="zh-Hant">經紀人；仲介；居中促成協議或交易</span>

### Collocations & patterns

- an insurance / real estate / stock broker
- broker a deal / an agreement
- broker peace
- act as a broker

### Example

A local broker helped the two companies broker an agreement.

<span class="reading-translation" lang="zh-Hant">一位當地仲介協助兩家公司促成協議。</span>

### Usage note

<p lang="zh-Hant">名詞指「仲介、經紀人」；動詞強調<strong>居中協調、促成</strong>，不只是買賣本身。<strong>Broker peace</strong> 表示斡旋促成和平。</p>

</section>

<section class="vocabulary-entry" aria-labelledby="businessperson">
<h2 id="businessperson">businessperson <span class="vocabulary-pos">[n.]</span></h2>

**Meaning:** <span lang="zh-Hant">商人；企業人士</span>

### Collocations & patterns

- a successful / local / prominent businessperson
- a young / retired businessperson
- businessperson of the year

### Example

Several local businesspeople attended the networking event.

<span class="reading-translation" lang="zh-Hant">幾位當地企業人士參加了這場交流活動。</span>

### Usage note

<p lang="zh-Hant"><strong>Businessperson</strong> 是不區分性別的單數形式；複數通常用 <strong>businesspeople</strong>。Businessperson of the Year 可作獎項名稱。</p>

</section>

<section class="vocabulary-entry" aria-labelledby="by-law">
<h2 id="by-law">by-law <span class="vocabulary-pos">[n.]</span></h2>

**Meaning:** <span lang="zh-Hant">地方自治法規；公司或組織的內部規章</span>

### Collocations & patterns

- a company / local / municipal by-law
- amend / adopt / violate a by-law
- under the by-law
- company bylaws

### Example

The members voted to amend the organization’s bylaws.

<span class="reading-translation" lang="zh-Hant">會員投票決定修訂組織的內部規章。</span>

### Usage note

<p lang="zh-Hant">也常拼作 <strong>bylaw</strong>，公司內規常用複數 <strong>bylaws</strong>。單數可數名詞通常需要冠詞：adopt <strong>a</strong> by-law；under <strong>the</strong> by-law 指依照前述規章。</p>

</section>
