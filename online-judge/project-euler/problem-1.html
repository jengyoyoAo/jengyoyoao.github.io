Project Euler · Problem 1

Multiples of 3 or 5

Find the sum of all natural numbers below 1,000 that are multiples of 3 or 5.

Project Euler 1Posted October 25, 2026View original problem ↗

Key idea

Check every integer below the limit. If it is divisible by 3 or 5, add it to a running total. Using a single OR condition means a number divisible by both (such as 15) is counted only once.

Implementation

Solution

n = 1000
total = 0

for i in range(1, n):
    if i % 3 == 0 or i % 5 == 0:
        total += i

print(total)
#include <stdio.h>

int main(void)
{
    int n = 1000;
    int total = 0;
    int i;

    for (i = 0; i < n; i++) {
        if (i % 3 == 0 || i % 5 == 0) {
            total += i;
        }
    }

    printf("%d\n", total);
    return 0;
}

Both versions output 233168. The C loop includes zero, which does not affect the sum.

Why it works

Each number below 1,000 is examined exactly once. The divisibility condition accepts precisely the numbers that are multiples of 3 or 5, and each accepted number is added once. Therefore, the final total is the required sum.

Complexity

  • Time: O(n), because the loop checks each number below the limit once.
  • Extra space: O(1), because the algorithm uses a fixed number of variables.

Takeaway

A direct scan keeps the solution simple and easy to verify. The OR condition is important: it avoids counting multiples of 15 twice.
