Open source

A first milestone · merged

My first open-source contribution · CodeTrial

I contributed to CodeTrial, an open-source project by NCKU computer science professor Jserv. Its C test harness previously printed non-finite values such as inf and NaN directly into JSON, causing the entire test run to lose its results.

I added a helper that serializes non-finite double values as JSON null, for both scalar and array outputs, and added regression tests for positive and negative infinity, NaN, and mixed arrays. The fix keeps valid test results available and brings the C harness in line with its C++ and Java counterparts.

Having my first PR merged felt like a first step from using open-source software to contributing back. It made open collaboration feel more within reach, and encouraged me to keep learning by taking part in public projects.
