My first open-source PR was merged

  • #OpenSource
  • #C
  • #Learning

My first pull request to an open-source project has been merged. It went into codetrial, an open-source project maintained by Jserv, a professor in National Cheng Kung University’s Department of Computer Science and Information Engineering.

What I worked on

The issue was that test results involving special floating-point values—positive infinity, negative infinity, or NaN—could produce invalid JSON and cause the harness to lose its results. I updated the C output helper to represent non-finite values as JSON null, for both individual doubles and arrays of doubles, and added regression cases for those values.

It was a focused fix, but it taught me to trace a bug from a report through the output code and tests, then check that the change handles both the simple and mixed cases.

A first step

I’ve used open-source software for a long time, so seeing my own contribution accepted felt like a meaningful first step toward giving back. It made contributing feel more tangible and encouraged me to keep learning by building, reading other people’s code, and sharing improvements.
